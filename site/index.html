A skill and a studio that teach your coding agent to make a web app feel like an app on phones. Shared by link: no app store, no separate mobile site.

Start here

Paste it into your coding agent. It installs the skill and opens the studio on your machine.

The appify studio, step by step

An animation of the studio. Lumen, a desktop-only photo app, runs off the screen on two phones. A comment is pinned on the iPhone and saved to .appify/comments.json. A coding agent reads it, moves the navigation to a bottom tab bar and saves checkpoint v2. The phones switch to Home Screen app mode, the studio shows a QR code for opening the app on a real phone, and History compares v1 with v2.

    The studio

    • Side by sideYour running app on a desktop window and several phones at once, with the room each phone really leaves after its bars.
    • CommentsPin a note on any device. It is saved to .appify/comments.json, and your coding agent reads it.
    • CheckpointsThe code, framed screenshots and facts after every step. Compare them, or play them back in History.
    • On my phoneA temporary HTTPS link and a QR code, to open the app on a real iPhone or Android.

    Phones

    • iPhone SE

    Inside each phone

    • Its own user agent
    • Touch, and no hover
    • Safe areas and notch
    • Browser tab or Home Screen
    • iOS zoom on small fields

    Good to know

    • Desktop Chrome underneath
    • No WebKit
    • No on-screen keyboard
    • Check on a real phone

    The skill · six steps, a checkpoint each

    1. 01ShellViewport, safe areas, overflow, scrolling, tap and hover.
    2. 02NavigationTab bar, top bar, sheets and menus, back behavior.
    3. 03LayoutGrids, sidebars, tables, cards, hover-only actions.
    4. 04InputForms, keyboards, autofill, file and camera inputs.
    5. 05InstallableManifest, icons, service worker, install prompts.
    6. 06ShareableLink previews, the share button, deep links.

    Setup prompt

    
            
    Paste it into your coding agent, in your project's folder. It installs the appify command and this skill, then opens the studio. Needs Node 20+, git and Chrome.
